# **App Name**: Blu Decor Padang

## Core Features:

- Pilihan Dekorasi Interaktif: Exploration grid for decoration packages including Lamaran, Akad, and Event with deep-dive technical inclusion modals (backdrop specs, lighting, props).
- AI Decor Moodboard Tool: A generative tool where clients describe their event vision to receive a custom decor theme suggestion and technical palette recommendation using the LLM.
- Portofolio Karya Filterable: Category-filtered visual gallery (Lamaran, Ultah, Aqiqah) with a premium lightbox view for close inspection of past decor work.
- Live Theme Toggle System: State-managed theme switcher between 'Navy Nights' (dark) and 'Ivory Minimalist' (light) for a luxury user experience.
- Cek Jadwal & WhatsApp Chat: Floating action buttons and schedule availability inquiries that bridge the user directly to WhatsApp using a natural pre-filled local greeting.
- Package Cost Estimator: Calculates approximate starting costs based on guest count and chosen specific props (gawang backdrop, par LED lighting).

## Style Guidelines:

- Primary color: Deep Sky Blue (#4eb4d6) for a premium tech-infused decor feel. Background: Deep Navy (#0c1215) for high-end nighttime vibes, mirroring the Padang business brand.
- Accent color: Tropical Mint (#13ebbc) used sparingly for CTA buttons and price highlights, providing high contrast against navy.
- Font pairing: 'Literata' (Serif) for headlines to evoke professional elegance, and 'Inter' (Sans-serif) for readable body text and service breakdowns.
- Thin-line Lucide React icons for props like lighting, curtains, and flowers to maintain a clean, high-design aesthetic.
- Asymmetrical hero banner with rounded arch imagery containers to mimic the physical decor elements like backdrops and welcome boards.
- Smooth, fluid Tailwind transitions for modal pops and filter filtering transitions, aiming for an organic human feel.
